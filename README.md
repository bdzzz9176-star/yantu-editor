# 研途编辑

面向电子、通信、集成电路考研公众号的内容研究与交付智能体。

当前阶段：集中固定“单校择校分析”模板和端到端交付链路。系统已接入模型API，但不自动发布。

## 当前能力

1. 识别文章属于就业盘点、专业方向解析、多校盘点或单校择校分析。
2. 根据文章类型选择固定模板。
3. 从指定资料中提取数据，并保留来源、版本、页码和统计口径。
4. 在写正文前给出范围、框架、数据缺口和待确认问题。
5. 生成正文、表格、图片需求和事实核查清单。
6. 重要结论必须由数据支持；资料不足时明确标记，不得补造。
7. 一份或多份资料可以被不同内容任务复用，任务之间相互隔离。
8. 单校任务已具备结构化解析、冲突审核、正文生成、按意见修改、版本记录、图表和Word导出。

## 当前文件

- `knowledge/writing_rules.md`：长期写作与沟通规则。
- `knowledge/source_catalog.md`：资料来源及使用方式。
- `templates/employment_article.md`：就业盘点文章模板。
- `templates/major_direction_article.md`：专业方向解析模板。
- `quality/acceptance_criteria.md`：交付前验收标准。
- `workflow/v0_workflow.md`：第一版运行流程。

## 当前重点

先用四川大学、福州大学、吉林大学等真实学校完成单校模板回归，固定资料选择、结构化提取、事实审核、模板化正文、修改版本和Word交付。单校模板达到稳定验收标准后，再重新规划下一类文章；当前不开发多校盘点。
