# 单校择校分析初稿评测规则

## 自动检查

1. 是否包含已确认标题和必要章节。
2. Markdown表格数量是否覆盖考试科目、复试线、录取和专业课。
3. 是否出现重复“结论：”模板句。
4. 是否出现无证据宣传词或无数据因果推断。
5. 是否保留异常数据、来源和适用届次说明。
6. 是否包含模型生成过程、提示词或内部工作流。

## 人工评测维度

每项使用“不通过 / 需修改 / 通过”，不使用虚假的综合百分制。

- **事实可靠性**：数字、专业、学院和口径能否追溯。
- **分析专业度**：是否围绕数据解释难度，而非复述表格或泛泛评价。
- **样本意识**：是否说明小样本、专项计划和异常统计的影响。
- **读者价值**：是否回答考什么、难在哪、适合谁、目标如何设定。
- **公众号表达**：是否自然、紧凑，标题有吸引力但不超过证据。
- **可编辑性**：结构、表格和段落能否直接进入编辑审核。

任一事实可靠性检查不通过时，不进入Word阶段。
