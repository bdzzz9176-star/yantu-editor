# 交付验收标准

## 一、范围正确

- [ ] 文章类型识别正确。
- [ ] 目标读者、年份、专业范围和输出格式已经明确。
- [ ] 边界专业经过判断；会影响整篇文章的争议项已由用户确认。
- [ ] 未遗漏用户点名的学校、专业、单位或赛道。

## 二、数据正确

- [ ] 每个数字可以追溯到当前任务的来源和页码/页面。
- [ ] 学校、学院、校区、专业代码和培养地点没有混用。
- [ ] 学硕、专硕、一志愿、调剂、专项和推免已经区分。
- [ ] 招生计划没有冒充录取人数。
- [ ] 复录比计算方法一致。
- [ ] 至少比较连续两年；需要稳定性判断时优先比较三年。
- [ ] 最低分个例没有被写成稳妥分数。
- [ ] 缺失数据明确标记，没有推测性补数。
- [ ] 事实、经验判断和预测在表述上可区分。

## 三、内容符合公众号风格

- [ ] 开头简短，直接说明读者问题。
- [ ] 每段只有一个主要结论。
- [ ] 没有大段空泛背景和机械式总结。
- [ ] 标题力度不超过证据力度。
- [ ] 分析回答了“为什么、是否稳定、适合谁”。
- [ ] 内部工作过程没有混入正式文章。

## 四、图片与来源

- [ ] 所有招聘图片均为真实页面、官方海报或明确标注的整理图。
- [ ] 没有重复图片和无意义的局部放大。
- [ ] 图注注明单位、届次、内容和来源。
- [ ] 历史招聘资料已注明仅作样本。
- [ ] 图片内容和正文结论一致。

## 五、Word交付

- [ ] 在指定模板或原文档基础上制作。
- [ ] 表格列数、颜色、字号和间距保持一致。
- [ ] 没有文字截断、图片遮挡、表格越界和异常空白页。
- [ ] 批注和修订已按交付要求保留或清除。
- [ ] 文档已完成逐页渲染检查；若环境无法渲染，必须明确说明。
