# 本地网页启动方式

最简单的方式：双击项目根目录中的 `启动研途编辑.bat`，浏览器会自动打开。

也可以在 PowerShell 中运行：

```powershell
& 'C:\Users\28472\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' 'D:\codexwork\研途编辑\app\server.py'
```

然后在浏览器打开：

`http://127.0.0.1:8765`
